# Alpemania.github.io
Portfolio

Preview localement (PHP) :

```bash
# Start PHP built-in server with the provided router for local preview
php -S 127.0.0.1:8000 .php-preview-router.php
# Then open http://127.0.0.1:8000/
```

Où mettre les images :

- Créez un dossier `Images/` à la racine du dépôt
- Placez vos fichiers nommés `image-1.jpg`, `image-2.jpg`, `image-3.jpg`

Notes :

- `send_mail.php` est un gestionnaire simple de formulaire : configurez la variable `$TO` avec votre adresse mail.
- `.htaccess` contient des règles utiles pour Apache, mais sera ignoré si vous hébergez sur GitHub Pages.
